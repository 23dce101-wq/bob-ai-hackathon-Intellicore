## Naming Convention

Screenshots follow the pattern: `01-<view-name>.png`

- `01-landing-page.png` — Landing page
- `02-dashboard.png` — Dashboard with KPIs
- `03-simulation.png` — Live terminal simulation
- `04-optimisation.png` — Optimisation & Gantt chart
- `05-controls.png` — Input controls & scenario builder
- `06-ai-copilot.png` — AI copilot & demo scenarios

## How to Add Screenshots

1. Run the application: `cd src && npm run dev`
2. Navigate to each tab and take a screenshot
3. Save to this directory with the naming convention above
4. Or run the save script: `python save_screenshots.py`
